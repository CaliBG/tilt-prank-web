App 使用方法

  1. 打开手机上安装的「水平仪」，平放手机，再慢慢抬高一端。默认是恶搞模式，实际倾斜 0–10° 都显示 0°，超过 10° 后显示实际角度减 10°。
  2. 在 App 内任意位置快速点两下，切到正常模式，读数会显示真实角度。
  3. 再双击一次，就切回恶搞模式。比如手机保持 15° 倾斜，两次双击前后的读数依次是 5° → 15° → 5°。

切换全程静默。彻底关闭 App 再打开，会回到恶搞模式。

本所温馨提示

仪器有点歪理。

用安卓手机浏览器打开网页，点击“开始测量”。把手机平放在物体表面，再慢慢倾斜，就能看到结果。若没有反应，请检查浏览器的动作传感器权限，或换用 Chrome 打开。

电脑和没有传感器的设备可以点击“先试玩一下”。试玩会明确标注模拟数据，不会读取手机姿态。

揭秘：它为什么这么乐观？

实际倾斜 0–10° 都显示 0°；超过 10° 后，显示实际角度减去 10°。例如 15° 显示 5°、20° 显示 10°。前后、左右和斜向都算。手机屏幕朝上或朝下，平放都算水平。

这是娱乐水平仪，不能用于施工或精密测量。传感器数据只在你的浏览器内处理，不会上传。可从浏览器菜单添加到主屏幕。
